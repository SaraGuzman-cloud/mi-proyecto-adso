# mi-proyecto-adso

Proyecto plantilla para el desarrollo de aplicaciones y sistemas bajo el programa **ADSO (Análisis y Desarrollo de Software)**, organizado en capas de base de datos, servidor y documentación.

## Stack tecnológico

* **JavaScript** (70.5%) — Lógica de aplicación, servicios y endpoints del servidor.
* **PLpgSQL** (29.5%) — Procedimientos, funciones, triggers y lógica en base de datos PostgreSQL.

## Estructura del repositorio

```text
mi-proyecto-adso/
├── database/   # Scripts SQL, esquemas, funciones PL/pgSQL y persistencia
├── docs/       # Documentación técnica, diagramas y análisis del proyecto
├── server/     # Código del servidor, rutas, controladores y configuración
└── readme.md   # Documentación general del repositorio
